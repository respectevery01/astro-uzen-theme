This guide demonstrates all Markdown styles supported by Margin. Use it as a reference when writing posts.

## Headings

Heading levels 2 through 4 are styled. Avoid using H1 in post body — the post title is already H1.

### This is H3

#### This is H4

## Text formatting

You can write **bold text**, *italic text*, and `inline code`. Links are styled with the accent color and an underline on hover.

## Lists

Unordered list:

- First item
- Second item
- Third item with a longer line to demonstrate wrapping behavior

Ordered list:

1. Step one
2. Step two
3. Step three

## Blockquotes

> This is a blockquote. It has a left border in the accent color and italic styling. Use it for pull quotes or notable passages.
